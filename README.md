# thermoprops
A web application that calculates various thermodynamic properties based on user inputs such as temperature
and pressure. It provides key outputs like entropy, enthalpy, and other relevant thermodynamic values, helping users easily perform
property calculations. The application also includes a unit conversion page, allowing for quick and convenient conversion between different
units. Tools used in the project are Python, Typescript, Fastapi, React, Postgresql, Docker, Git and aws Ec2.
